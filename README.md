# students_mark_analysis
Students Mark Analysis using AI

Project Overview

This project analyzes the academic performance of 50 students using Microsoft Excel, Microsoft Word, and Microsoft PowerPoint.

The project includes:

Student marks dataset

Excel formulas and analysis

Teacher insights

Academic performance reporting

Dashboard and visualization concepts

Features

Excel Analysis

Total marks calculation

Average calculation

Grade generation

Pass/Fail status

Conditional formatting

Data analysis

Teacher Insights

Top-performing students

Students requiring support

Subject-wise analysis

Academic recommendations

Reporting

MS Word project report

PowerPoint presentation

Ready-to-submit academic project

Key Insights

Maths and Computer are the strongest subjects.

Most students scored between 70–90.

Very few students require additional academic support.

Balanced students achieved better overaall performance
